The 4 paired FDR hits

  • Tuba1a: not in the 721 list; 1 of its four values is imputed, so it leans on a filled-in number. Paired adjusted p 0.0097.

Read with care. With 2 pairs there is only 1 residual degree of freedom, so these hits are leads, not findings. They vanish under plain eBayes (0 hits). This is not a replacement for the main analysis. I would like your view on whether to adopt it.

6 Caveats

A Nothing is statistically significant
0 of 1938 proteins pass FDR < 0.05 and g:Profiler has 0 significant terms, so this is exploratory. With 2 biological replicates per group from separate experiments, power is low. (Smallest adjusted p on the list: 0.116.)
B The five assigned values are unconfirmed stand-ins
EGF, EREG, EFNA4, TYRO3, MFAP4 were seen in the controls only. I assigned the 100-fold decrease (log2FC -6.643856) so that IPA could accept these proteins. It is not measured and not an estimate of the true change.
C IPA used its default reference set
Both IPA runs used the default reference (the whole database), which makes IPA p-values inflated. Compare order and z-scores, not p-values.
D Row caps and different table sizes
The Diseases and functions export is capped at 1000 rows in both runs, so a disease can be missing from one run only because of the cap. The upstream tables have 2277 rows in run 2 (721) against 2431 in the 716 run, so some regulators exist in only one run.
