2 Four things to know before quoting a number

Tap a heading to open or close.

A Nothing is statistically significant
0 of the 968 proteins pass FDR < 0.05, and 0 enriched terms pass in g:Profiler. With one biological sample per group, animal-to-animal variation cannot be seen.
B The −6.64 values are stand-ins, not measurements
EGF, EREG, EFNA4, TYRO3 and MFAP4 were detected in both control readings and not detected after testosterone, so no fold change can be measured. A 100-fold decrease (log2 = −6.64) was used as the stand-in, as discussed, so the software would accept them. The two control readings of the same sample can differ several-fold (up to about 17x for EGF), so 100-fold is a rough convention, not an estimate of the true drop. It is labelled “assigned” in every file. “Not detected” can also mean below the detection limit.
C The 247 are not the “no problems” set
You asked for recovered proteins changed by at least 50% with no problems. All 247 changed by at least 1.5x, but each has one or two imputed readings (178 have one, 69 have two). I included them and flagged them in the manifest. They can be removed if you prefer.
D IPA used its default reference set
IPA refused the reference set I tried (the measured proteome: “too large an overlap”), so both runs used its default, the whole database. That inflates IPA’s p-values: compare rankings and z-scores, not p-values. g:Profiler and STRING also changed database versions since the 715 run, so compare against the same-version control folder.
